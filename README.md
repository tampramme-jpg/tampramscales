# TamPramScale — Digital Growth Agency Static Website

A high-performance, dark-glassmorphism static website designed specifically for GitHub Pages deployment.

## GitHub Pages Setup Guide

### 1. Create a Repository
1. Log into your GitHub account and click **New Repository**.
2. Name your repository (e.g., `tampramscales` or `tampramscale`).
3. Set visibility to **Public** and leave "Initialize with README" unchecked.
